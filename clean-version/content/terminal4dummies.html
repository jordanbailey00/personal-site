terminal4dummies teaches the command line the way most of us actually learn it: by typing commands and seeing what happens. Everything runs in the browser, in a simulated Linux shell, so there is nothing to install and nothing to break.

What’s inside

  • Lessons that walk from moving around folders to tests, loops, and scripts, each with steps that check off as you complete them.
  • An emulator that behaves like a real bash prompt, with history, tab completion, and the usual keyboard shortcuts.
  • A commands reference for looking things up as you go.

The shell is written from scratch in TypeScript, and its behavior is tested against real bash.
